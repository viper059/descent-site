วิธีติดตั้งเว็บ ช่างหนุ่มอยุธยา Descent

1) แตกไฟล์ ZIP จะได้โฟลเดอร์ descent-site
2) อัปโหลดโฟลเดอร์นี้ไปที่โฮสต์เว็บ เลือกอย่างใดอย่างหนึ่ง
   - Netlify: เข้า app.netlify.com/drop แล้วลากโฟลเดอร์ descent-site ไปวาง ได้ลิงก์ใช้งานทันที
   - Cloudflare Pages: Create project > Upload assets > เลือกโฟลเดอร์
   - GitHub Pages: อัปโหลดไฟล์ขึ้น repository แล้วเปิด Pages
3) ถ้ามีโดเมน เช่น descent-ayutthaya.com ให้ตั้ง Custom domain ในหน้าตั้งค่าของโฮสต์

แก้เนื้อหาที่ไฟล์ data.js ไฟล์เดียว (เบอร์โทร ผลงาน วิดีโอ ผู้ติดตาม ที่อยู่)
- เพิ่มรูปผลงาน: ใส่ไฟล์รูปในโฟลเดอร์ img แล้วเพิ่มรายการใน works
- เพิ่มวิดีโอ: เพิ่มรายการใน videos ใส่ลิงก์ YouTube หรือ Facebook ในช่อง url
- embedVideos: true คือเล่นวิดีโอในหน้าเว็บ (ตั้งไว้แล้ว) ถ้าต้องการให้กดไปเปิดบน YouTube ให้เปลี่ยนเป็น false
- ตัวเลขผู้ติดตาม (followers) ต้องแก้เองเมื่อเปลี่ยน เว็บนี้ไม่ได้ดึงตัวเลขสดจาก Facebook

เปิดทดสอบบนเครื่อง: เปิดไฟล์ index.html ด้วยเบราว์เซอร์ได้เลย (วิดีโอฝังต้องเปิดผ่านโฮสต์จริงหรือเว็บเซิร์ฟเวอร์ จึงจะเล่นได้ครบ)
